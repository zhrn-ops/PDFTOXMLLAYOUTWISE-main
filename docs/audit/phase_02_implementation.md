## Defects addressed

- **A01:** missing schemas can no longer produce schema-valid status; syntax and metadata checks are separate from schema validation. ANI cannot use the legacy JATS profile. A missing/invalid local bundle blocks strict export.
- **A03:** serializer no longer inserts whitespace into inline formulas and unknown inline content. Known structural metadata containers retain the editor's established line formatting.
- **A04:** generator and correction exports share atomic publication. Injected short writes, interrupted writes, fsync failures and replace failures preserve existing output.
- **A02, boundary prerequisite only:** Unicode editor/session text no longer keeps a conflicting non-UTF-8 byte declaration; a Latin-1 character round-trip and raw Unicode edit are tested. Broader revision-history/workspace integrity work remains Phase 3.

Existing regeneration/archive behavior was preserved. No CI, dependency upgrade, large refactor, CLI repair, alphabetic-script fix, performance optimization or new provider integration was undertaken.

## Intentional behavior changes and remaining limits

- Previous **Validate & Export** is visibly renamed **Draft Export**; its provisional capability remains available. A separate strict export requires a chosen XSD.
- Schema-invalid XML may be intentionally exported as a draft with visible issues. It cannot be exported through the validated action.
- Legacy `Validator.validate()` reports schema unavailability. Internal draft callers use separate dimensions so this warning does not masquerade as lost output.
- The supported desktop application already declares/requires lxml. Standalone validator/generator draft support without lxml is retained, explicitly reports schema unavailability, and rejects DTD input. The generator's stdlib path no longer passes an unsupported `nsmap=None` attribute.
- Schema bundles must be self-contained below the selected entry schema folder; network resources, parent-folder dependencies and schema DTDs are rejected with an actionable error. The profile selection is not persisted in `.jatsdraft` files in this phase.
- No authoritative ANI/CAR or JATS publisher bundle was supplied or installed. Real publisher validation remains unavailable until the appropriate resources are selected. XSD success does not assert additional publisher business-rule compliance.
- Revision provenance persistence, other A02 transitions, alphabetic scripts (A06), CLI compatibility (A05), shutdown/cancellation risks and other audit findings remain for their approved phases.

Recommended next step: review Phase 2, then approve Phase 3 separately for revision integrity. This report is not the final engineering review or a production-readiness certification.
